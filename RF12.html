Casos de Prueba - Libreria

1. Introducción

Este documento define el caso de prueba y el ambiente de pruebas para la funcionalidad de **realización de inventarios cíclicos y comparación con el stock registrado**. El sistema deberá permitir al encargado de inventario realizar conteos periódicos de los productos y comparar las cantidades físicas registradas con las existencias almacenadas en el sistema.

2. Alcance de las pruebas (Qué se va a probar)

a. Código del Ticket #1201
b. Descripción de la historia El sistema deberá permitir realizar inventarios cíclicos y comparar resultados con el stock registrado. Se verificará que las cantidades contadas puedan registrarse y compararse con las existencias almacenadas en el sistema.

3. Fuera de Alcance

  • Pruebas de rendimiento: No se evaluarán inventarios masivos con grandes cantidades de productos.
  • Pruebas de seguridad: No se realizarán pruebas de penetración.
  • Compra de productos: No se evaluará el proceso de abastecimiento.
  • Registro de nuevos libros: No se evaluará la creación de productos.
  • Generación de reportes: No se evaluará específicamente la generación de reportes de movimientos.

4. Tipos de prueba / Estrategia (Cómo ejecutar las pruebas)

  • Prueba funcional: Verificar que se pueda realizar un inventario cíclico.
  • Prueba de validación: Comprobar que las cantidades ingresadas sean comparadas correctamente.
  • Prueba de escenarios: Realizar conteos con cantidades iguales, superiores e inferiores al stock registrado.
  • Prueba de diferencias: Verificar que el sistema identifique correctamente las diferencias.
  • Prueba exploratoria: Realizar inventarios sobre diferentes libros y cantidades.
  • Cross-browser testing (Múltiples browsers): Verificar el funcionamiento en Chrome, Firefox y Edge.
  • Cross mobile testing (Emulado con Chrome): Comprobar el acceso mediante dispositivos móviles o emulación móvil.

6. Datos de pruebas

Los datos utilizados para las pruebas serán los siguientes:

Usuario Usuario autorizado para realizar inventarios.
Libro Libro seleccionado para el conteo.
Stock registrado Cantidad de unidades almacenadas en el sistema.
Cantidad física Cantidad encontrada durante el conteo.
Diferencia Resultado de comparar el stock registrado con la cantidad física.
Inventario cíclico Registro del conteo realizado.
Fecha del inventario Fecha en la que se realiza el conteo.
Resultado Coincidencia o diferencia entre las cantidades.

7. Riesgos

Riesgo Probabilidad Impacto Mitigación
El sistema no permite registrar el conteo Media Alto Realizar inventarios con diferentes productos.
La comparación de cantidades es incorrecta Media Alto Probar diferentes cantidades físicas y registradas.
No se detectan diferencias Media Alto Realizar escenarios donde las cantidades sean diferentes.
Se registra un producto incorrecto Baja Alto Validar el código y nombre del libro antes del conteo.
El inventario no queda guardado Media Alto Consultar el inventario después de finalizar el proceso.
Los resultados del inventario son inconsistentes Media Alto Repetir el conteo y comparar los resultados obtenidos.
