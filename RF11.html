Casos de Prueba - Libreria

1. Introducción

Este documento define el caso de prueba y el ambiente de pruebas para la funcionalidad de **configuración de alertas automáticas de inventario**. El sistema deberá permitir al encargado de inventario establecer niveles mínimos personalizados para cada libro, a partir de los cuales se generarán alertas automáticas.

2. Alcance de las pruebas (Qué se va a probar)

a. Código del Ticket #1101
b. Descripción de la historia El sistema deberá permitir al encargado de inventario configurar alertas automáticas por niveles mínimos personalizados para cada libro. Se verificará que los niveles puedan configurarse y que las alertas se generen de acuerdo con el valor establecido para cada producto.

3. Fuera de Alcance

  • Pruebas de rendimiento: No se evaluará la configuración masiva de alertas.
  • Pruebas de seguridad: No se realizarán pruebas de penetración.
  • Reposición de inventario: No se evaluará la compra o ingreso de nuevos productos.
  • Generación de reportes: No se evaluará la generación de reportes de inventario.
  • Notificaciones externas: No se evaluarán servicios externos de mensajería.

4. Tipos de prueba / Estrategia (Cómo ejecutar las pruebas)

  • Prueba funcional: Verificar que se pueda configurar un nivel mínimo por libro.
  • Prueba de validación: Comprobar que el valor configurado sea almacenado correctamente.
  • Prueba de límites: Probar valores mínimos, valores altos y valores no válidos.
  • Prueba de escenarios: Configurar diferentes niveles para diferentes libros.
  • Prueba de alertas: Verificar que cada libro genere alertas según su propio nivel.
  • Cross-browser testing (Múltiples browsers): Verificar el funcionamiento en Chrome, Firefox y Edge.
  • Cross mobile testing (Emulado con Chrome): Comprobar el funcionamiento mediante dispositivos móviles o emulación móvil.

5. Ambiente de prueba

Acceder al Ambiente de Pruebas

6. Datos de pruebas

Los datos utilizados para las pruebas serán los siguientes:

Usuario Usuario con permisos para gestionar inventario.
Libro Libro seleccionado para configurar la alerta.
Stock actual Cantidad actual de unidades disponibles.
Nivel mínimo Valor personalizado establecido para generar la alerta.
Nuevo nivel mínimo Valor utilizado para comprobar la actualización de la configuración.
Movimiento Operación utilizada para disminuir el stock.
Stock resultante Existencias después del movimiento.
Alerta Notificación generada al alcanzar el nivel mínimo.

7. Riesgos

Riesgo Probabilidad Impacto Mitigación
El sistema no permite configurar el nivel mínimo Media Alto Probar diferentes libros y valores.
El nivel configurado no se guarda Media Alto Consultar nuevamente la configuración después de guardarla.
La alerta utiliza un valor incorrecto Media Alto Comparar el nivel configurado con el momento en que se genera la alerta.
Un libro utiliza el nivel de otro libro Baja Alto Configurar valores diferentes para varios libros y comprobar las alertas.
Se aceptan valores inválidos Media Medio Probar valores negativos, vacíos o formatos incorrectos.
La actualización del nivel no tiene efecto Media Alto Modificar el nivel y realizar nuevamente movimientos de inventario.
