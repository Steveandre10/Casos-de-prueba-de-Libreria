Casos de Prueba - Libreria

1. Introducción

Este documento define el caso de pruebas y el ambiente de pruebas para la funcionalidad de gestión de cuentas de usuario. El sistema deberá permitir al administrador crear, editar y eliminar registros de usuarios, verificando que las operaciones se realicen correctamente y que la información de las cuentas se mantenga actualizada.

2. Alcance de las pruebas (Qué se va a probar)

a. Código del Ticket #0302
b. Descripción de la historia El sistema deberá permitir al administrador gestionar las cuentas de usuario mediante la creación, edición y eliminación de registros. Se verificará que el administrador pueda crear nuevas cuentas, modificar la información de usuarios existentes y eliminar registros correctamente, manteniendo la integridad de los datos.

3. Fuera de Alcance

  • Pruebas de rendimiento: No se evaluará el comportamiento de la gestión de usuarios bajo una cantidad elevada de registros o usuarios simultáneos.
  • Pruebas de seguridad: No se realizarán pruebas de penetración ni análisis especializado de vulnerabilidades sobre el módulo de gestión de usuarios.
  • Recuperación de registros: No se probará la recuperación de cuentas eliminadas de forma permanente.
  • Procesamiento de pagos: El proceso de pago no será evaluado en profundidad, ya que la prueba se concentra en la creación, edición y eliminación de cuentas de usuario.

4. Tipos de prueba / Estrategia (Cómo ejecutar las pruebas)

  • Pruebas ágiles / funcionales basadas en historias de usuario + exploración: Verificar que el administrador pueda crear, editar y eliminar cuentas de usuario correctamente.
  • Prueba de validación: Comprobar que los datos ingresados al crear o editar una cuenta sean almacenados y actualizados correctamente.
  • Prueba de creación: Verificar que el administrador pueda registrar un nuevo usuario y que el registro quede almacenado correctamente.
  • Prueba de edición: Verificar que el administrador pueda modificar los datos de un usuario existente y que los cambios se reflejen correctamente.
  • Prueba de eliminación: Verificar que el administrador pueda eliminar un registro de usuario y que este deje de estar disponible en la gestión de cuentas.
  • Cross-browser testing (Múltiples browsers): Verificar la gestión de cuentas utilizando diferentes navegadores como Chrome, Edge y Firefox.
  • Cross mobile testing (Emulado con Chrome): Comprobar que el administrador pueda gestionar las cuentas desde un dispositivo móvil mediante la emulación de Chrome.

6. Datos de pruebas

Los datos utilizados para las pruebas serán los siguientes:

Administrador Usuario con rol de administrador y permisos para gestionar las cuentas de usuario.
Usuario de prueba Registro de usuario utilizado para realizar las pruebas de creación, edición y eliminación.
Datos del usuario Información requerida para crear y editar una cuenta, como nombre, correo electrónico y contraseña.
Registro existente Cuenta de usuario previamente registrada que será utilizada para realizar las pruebas de edición y eliminación.
Identificador de usuario Identificador válido asociado al registro que permitirá realizar operaciones de edición y eliminación.
Datos modificados Información actualizada de un usuario existente para validar la operación de edición.
Confirmación de eliminación Acción o mecanismo utilizado para confirmar la eliminación de un registro de usuario.
Estado del registro Estado esperado del usuario después de realizar una operación de creación, edición o eliminación.

7. Riesgos

Riesgo Probabilidad Impacto Mitigación
El administrador no puede crear un nuevo usuario Media Alto Verificar los campos requeridos y realizar pruebas de creación con datos válidos.
La información del usuario no se actualiza correctamente Media Alto Editar los datos de diferentes usuarios y comprobar que los cambios se almacenen correctamente.
El administrador no puede eliminar un usuario Media Alto Verificar los permisos del administrador y realizar pruebas de eliminación con registros existentes.
Se permite crear usuarios con información inválida Media Alto Realizar pruebas con campos vacíos, correos inválidos o datos incompletos y verificar las validaciones del sistema.
Se elimina un registro de usuario incorrecto Bajo Alto Verificar el identificador y los datos del usuario antes de confirmar la eliminación.
La gestión de usuarios presenta errores en dispositivos moviles Media Medio Realizar pruebas de creación, edición y eliminación utilizando diferentes tamaños de pantalla y emulación móvil.
