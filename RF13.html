Casos de Prueba - Libreria

1. Introducción

Este documento define el caso de prueba y el ambiente de pruebas para la funcionalidad de **registro de nuevos libros y actualización de información del stock**. El sistema deberá permitir al encargado de inventario registrar nuevos libros y modificar la información relacionada con sus existencias.

2. Alcance de las pruebas (Qué se va a probar)

a. Código del Ticket #1301
b. Descripción de la historia El sistema deberá permitir al encargado de inventario registrar nuevos libros y actualizar la información del stock. Se verificará que los nuevos libros puedan ser registrados correctamente y que sus cantidades de existencias puedan ser actualizadas.

3. Fuera de Alcance

  • Pruebas de rendimiento: No se evaluará el registro masivo de libros.
  • Pruebas de seguridad: No se realizarán pruebas de penetración.
  • Proceso de compra: No se evaluará la compra de libros por parte de los usuarios.
  • Gestión de devoluciones: No se evaluará el proceso de devolución.
  • Reportes de inventario: No se evaluará específicamente la generación de reportes.

4. Tipos de prueba / Estrategia (Cómo ejecutar las pruebas)

  • Prueba funcional: Verificar que se pueda registrar un nuevo libro.
  • Prueba de validación: Comprobar que los datos obligatorios sean aceptados correctamente.
  • Prueba de actualización: Verificar que el stock pueda modificarse.
  • Prueba de campos: Probar datos válidos, vacíos, duplicados o formatos incorrectos.
  • Prueba de escenarios: Registrar diferentes libros con diferentes cantidades.
  • Prueba exploratoria: Realizar registros y actualizaciones con diferentes combinaciones de información.
  • Cross-browser testing (Múltiples browsers): Verificar el funcionamiento en Chrome, Firefox y Edge.
  • Cross mobile testing (Emulado con Chrome): Comprobar el funcionamiento mediante dispositivos móviles o emulación móvil.

6. Datos de pruebas

Los datos utilizados para las pruebas serán los siguientes:

Usuario Usuario autorizado para gestionar inventario.
Título del libro Nombre válido del nuevo libro.
Autor Autor correspondiente al libro.
ISBN Identificador válido del libro, si aplica.
Categoría Categoría correspondiente al libro.
Precio Precio de venta del libro.
Stock inicial Cantidad inicial de unidades registradas.
Stock actualizado Nueva cantidad de existencias.
Código del libro Identificador utilizado para consultar el libro.

7. Riesgos

Riesgo Probabilidad Impacto Mitigación
El sistema no permite registrar un nuevo libro Media Alto Realizar registros utilizando diferentes datos válidos.
Se permite registrar libros duplicados Media Alto Intentar registrar nuevamente un libro con el mismo identificador.
Los datos del libro no se guardan correctamente Media Alto Consultar el libro después del registro y comparar la información.
El stock no se actualiza correctamente Media Alto Modificar diferentes cantidades y verificar los resultados.
Se aceptan cantidades de stock inválidas Media Medio Probar valores negativos, vacíos y formatos incorrectos.
El libro registrado no aparece en el inventario Baja Alto Buscar el libro mediante su código o identificador.
