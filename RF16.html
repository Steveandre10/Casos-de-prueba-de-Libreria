Casos de Prueba - Libreria

1. Introducción

Este documento define el caso de pruebas y el ambiente de pruebas para la funcionalidad de configuración básica del sistema. El sistema deberá permitir al administrador ajustar opciones básicas, como los métodos de pago y envío, verificando que las configuraciones se puedan crear, modificar y aplicar correctamente.

2. Alcance de las pruebas (Qué se va a probar)

a. Código del Ticket #0301
b. Descripción de la historia El sistema deberá permitir al administrador ajustar opciones básicas del sistema, como métodos de pago y envío. Se verificará que el administrador pueda consultar, modificar y guardar estas configuraciones correctamente y que los cambios se apliquen de acuerdo con las opciones seleccionadas.

3. Fuera de Alcance

  • Pruebas de rendimiento: No se evaluará el comportamiento de las configuraciones bajo una cantidad elevada de cambios o usuarios simultáneos.
  • Pruebas de seguridad: No se realizarán pruebas de penetración ni análisis especializado de vulnerabilidades sobre las opciones de configuración.
  • Integración con proveedores externos: No se evaluará en profundidad el funcionamiento interno de las plataformas externas de pago o empresas de envío.
  • Procesamiento de pagos y envíos: No se evaluará en profundidad la operación completa de las transacciones o entregas, ya que la prueba se concentra en la configuración de sus opciones básicas.

4. Tipos de prueba / Estrategia (Cómo ejecutar las pruebas)

  • Pruebas ágiles / funcionales basadas en historias de usuario + exploración: Verificar que el administrador pueda ajustar las opciones básicas de métodos de pago y envío correctamente.
  • Prueba de validación: Comprobar que las opciones seleccionadas sean válidas y que los cambios se almacenen correctamente.
  • Prueba de métodos de pago: Verificar que el administrador pueda habilitar, deshabilitar o modificar los métodos de pago disponibles en el sistema.
  • Prueba de métodos de envío: Verificar que el administrador pueda configurar las opciones de envío disponibles y sus parámetros básicos.
  • Prueba de aplicación de configuración: Comprobar que los cambios realizados por el administrador se reflejen correctamente en las opciones disponibles para los usuarios.
  • Cross-browser testing (Múltiples browsers): Verificar la configuración de métodos de pago y envío utilizando diferentes navegadores como Chrome, Edge y Firefox.
  • Cross mobile testing (Emulado con Chrome): Comprobar que el administrador pueda ajustar estas opciones desde un dispositivo móvil mediante la emulación de Chrome.

6. Datos de pruebas

Los datos utilizados para las pruebas serán los siguientes:

Administrador Usuario con rol de administrador y permisos para ajustar las opciones básicas del sistema.
Configuración actual Opciones de métodos de pago y envío actualmente configuradas en el sistema.
Métodos de pago Opciones de pago disponibles para ser habilitadas, deshabilitadas o ajustadas por el administrador.
Métodos de envío Opciones de envío disponibles para ser configuradas por el administrador.
Parámetros de configuración Datos básicos asociados a los métodos de pago y envío que podrán ser ajustados por el administrador.
Configuración modificada Valores actualizados por el administrador para validar que los cambios se almacenen correctamente.
Estado de las opciones Estado habilitado o deshabilitado de los métodos de pago y envío configurados.
Resultado esperado Configuración guardada correctamente y aplicada en las opciones correspondientes del sistema.

7. Riesgos

Riesgo Probabilidad Impacto Mitigación
El administrador no puede modificar las opciones de pago Media Alto Verificar los permisos del administrador y realizar pruebas con diferentes métodos de pago.
La configuración de los métodos de envío no se actualiza correctamente Media Alto Modificar diferentes opciones de envío y comprobar que los cambios se almacenen correctamente.
Los cambios de configuración no se aplican correctamente Media Alto Guardar diferentes configuraciones y verificar que las opciones modificadas se reflejen correctamente en el sistema.
Se permiten configuraciones con datos inválidos Media Alto Realizar pruebas con valores vacíos, inválidos o incompletos y verificar las validaciones del sistema.
Se modifica una opción de configuración incorrecta Bajo Alto Verificar la opción seleccionada y los valores ingresados antes de guardar los cambios.
La configuración presenta errores en dispositivos moviles Media Medio Realizar pruebas de configuración utilizando diferentes tamaños de pantalla y emulación móvil.
