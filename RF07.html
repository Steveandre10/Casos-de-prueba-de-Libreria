Casos de Prueba - Libreria

1. Introducción

Este documento define el caso de prueba y el ambiente de pruebas para la funcionalidad de búsqueda de facturas utilizando criterios simples. El sistema deberá permitir al encargado de facturación localizar facturas de manera rápida mediante criterios como la fecha o el número de pedido.

2. Alcance de las pruebas (Qué se va a probar)

a. Código del Ticket #0701
b. Descripción de la historia El sistema deberá permitir al encargado buscar facturas utilizando criterios simples como fecha o número de pedido. Se verificará que el sistema permita realizar búsquedas utilizando estos criterios y que presente correctamente las facturas que coincidan con la información ingresada.

3. Fuera de Alcance

  • Pruebas de rendimiento: No se evaluará la búsqueda sobre una cantidad masiva de facturas.
  • Pruebas de seguridad: No se realizarán pruebas de penetración sobre el módulo de facturación.
  • Modificación de facturas: No se evaluará la edición de las facturas encontradas.
  • Generación de facturas: No se evaluará la creación de nuevas facturas, ya que el objetivo es únicamente realizar búsquedas.
  • Reportes de transacciones: No se evaluará la generación de reportes históricos, ya que corresponde al RF6.

4. Tipos de prueba / Estrategia (Cómo ejecutar las pruebas)

  • Prueba funcional: Verificar que el sistema permita realizar búsquedas de facturas.
  • Prueba de validación: Comprobar que las facturas encontradas correspondan exactamente con los criterios utilizados.
  • Prueba de filtros: Realizar búsquedas utilizando fecha y número de pedido.
  • Prueba de escenarios: Utilizar facturas existentes, inexistentes y criterios inválidos.
  • Prueba exploratoria: Realizar búsquedas con diferentes combinaciones y formatos de datos para identificar errores.
  • Cross-browser testing (Múltiples browsers): Verificar el funcionamiento en Chrome, Firefox y Edge.
  • Cross mobile testing (Emulado con Chrome): Comprobar el acceso y funcionamiento mediante dispositivos móviles o emulación móvil.

6. Datos de pruebas

Los datos utilizados para las pruebas serán los siguientes:

Usuario Usuario registrado con permisos para consultar facturas.
Número de pedido Número válido de un pedido asociado a una factura.
Factura Factura previamente generada y registrada en el sistema.
Fecha de factura Fecha válida correspondiente a una factura existente.
Criterio de búsqueda Fecha o número de pedido utilizado para localizar la factura.
Factura inexistente Número de pedido o fecha que no tenga facturas asociadas.
Resultado de búsqueda Factura o conjunto de facturas que coincidan con el criterio ingresado.
Estado de factura Estado actual de la factura encontrada.

7. Riesgos

Riesgo Probabilidad Impacto Mitigación
El sistema no encuentra una factura existente Media Alto Realizar búsquedas utilizando diferentes fechas y números de pedido válidos.
El sistema muestra facturas que no coinciden con el criterio Media Alto Comparar los resultados con la información registrada en la base de datos.
El número de pedido no permite encontrar la factura asociada Media Alto Verificar la relación entre el pedido y la factura.
La búsqueda por fecha presenta resultados incorrectos Media Medio Realizar pruebas con diferentes fechas y verificar los resultados.
El sistema no informa cuando no existen resultados Baja Medio Realizar búsquedas con datos inexistentes y verificar el mensaje mostrado.
El sistema presenta resultados incompletos Media Alto Comparar los resultados obtenidos con las facturas registradas para el criterio utilizado.
