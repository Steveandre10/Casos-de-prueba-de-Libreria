Casos de Prueba - Libreria (Moderación de Reseñas)

1. Introducción

Este documento define los casos de prueba y el ambiente de pruebas para la funcionalidad de moderación de reseñas y contenidos generados por los usuarios. El sistema deberá permitir al administrador aprobar, rechazar o eliminar reseñas y comentarios, garantizando que el contenido publicado cumpla con las políticas de la plataforma.

2. Alcance de las pruebas

a. Código del Ticket #0307
b. Descripción de la historia El sistema deberá permitir al administrador aprobar o moderar reseñas y contenidos generados por los usuarios. Se verificará que las reseñas puedan ser revisadas antes de publicarse y que el administrador tenga la opción de aprobar, rechazar o eliminar contenido inapropiado.

3. Fuera de Alcance

  • Pruebas de rendimiento: No se evaluará la moderación con miles de reseñas simultáneas.
  • Filtros automáticos: No se probarán algoritmos de moderación automática basados en IA.
  • Integración externa: No se evaluará la exportación de reseñas hacia sistemas externos.

4. Tipos de prueba / Estrategia

  • Prueba funcional: Verificar que el administrador pueda aprobar, rechazar o eliminar reseñas.
  • Prueba de validación: Comprobar que las reseñas aprobadas se muestren correctamente en el catálogo.
  • Prueba de restricción: Validar que las reseñas rechazadas no sean visibles para los usuarios.
  • Prueba exploratoria: Moderar diferentes tipos de contenido para identificar inconsistencias.
  • Cross-browser testing: Validar la moderación en Chrome, Edge y Firefox.
  • Cross mobile testing: Comprobar que la moderación sea accesible desde dispositivos móviles.

5. Ambiente de prueba

La prueba se realizará en un ambiente aislado de producción, con la versión más reciente del código.

Acceder al Ambiente de Pruebas

6. Datos de pruebas

Usuarios internos Administrador
Usuarios externos Clientes registrados que generan reseñas
Reseñas Comentarios sobre productos (positivos, negativos, inapropiados)
Acciones del administrador Aprobar, rechazar, eliminar reseñas

7. Riesgos

Riesgo Probabilidad Impacto Mitigación
El administrador no puede aprobar reseñas Media Alto Validar la funcionalidad en diferentes escenarios.
Las reseñas rechazadas siguen visibles Alta Alto Probar la restricción de visibilidad tras rechazo.
El sistema elimina reseñas aprobadas por error Baja Medio Verificar consistencia en la base de datos.
Errores de visualización en móviles Media Medio Realizar pruebas de compatibilidad móvil.
